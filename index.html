Regras de Segurança do Firebase Realtime Database

Copie as regras abaixo e cole no painel Firebase Console > Realtime Database > Regras para restringir acessos não autorizados:

{
  "rules": {
    "users": {
      "$uid": {
        ".read": "auth != null && auth.uid === $uid",
        ".write": "auth != null && auth.uid === $uid"
      }
    }
  }
}
